# Gene View

A scroll-driven, holographic 3D tour of DNA. Scroll to explore the double helix, nucleotides, base pairing, hydrogen bonds, replication, chromatin packing, and chromosomes. At the end you dive into a real gene, human β-globin (HBB), where you can swipe through its parts and click them to learn more.

Built with Three.js as a single static `index.html`, for Hack Club.

## Run locally

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765.
